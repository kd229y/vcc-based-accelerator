## 比較時注意

- 固定版本不代表沒有 bug。依設計筆記記錄，fork 的 CAPT baseline 有已知漏判問題，不能拿它當唯一正確性標準；應使用獨立暴力檢查與已確認的幾何參考。此次沒有另行下載修正版 CAPT。
- 中心點濾波容量不足可能丟點；正式 baseline 必須監測 overflow，不能接受靜默資料遺失。
- Panda `panda.hh` 的 `max_radius` 不能直接視為所有階層查詢球的最大半徑；需核對實際 FKCC 路徑中的外層球。
- 模型 URDF、SRDF、FK 常數與手指開度應保持同一版本，不與其他資料集任意混用。
- `data/panda_model_summary.json` 是 URDF 解析摘要，不能單憑球數相同就認定與產生的 C++ 模型完全等價。
